REST Automation

API 接入指南

外部脚本与 AI Agent 可通过请求头 Authorization: Bearer <密码> 或 x-api-key 调用接口。

POST /api/generate

创建随机或自定义前缀邮箱，支持设置所属域名与有效时长（0 表示永久有效）。

GET /api/mailbox/:address/wait?timeout=30

阻塞长轮询等待指定邮箱的新来信，收到邮件立即返回完整正文，适合自动化接码流程。

GET /api/mailboxes

获取全部已创建临时邮箱及其各自的收件数量、创建时间与到期时间。

GET /api/mailbox/:address

查看指定邮箱的邮件列表；配合 GET /api/email/:id 读取完整文本与 HTML 内容。

DELETE /api/mailboxes/:address

删除指定临时邮箱及其名下全部本地邮件记录。

GET /api/config

读取当前站点已启用的全部收信域名列表与默认域名。
